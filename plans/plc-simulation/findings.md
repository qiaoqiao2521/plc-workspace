# Findings

- Reza-Controls/plc-ladder-logic-conveyor has a concrete HTTP-input-simulator / OpenPLC Modbus-output test harness. Inspected its source: https://github.com/Reza-Controls/plc-ladder-logic-conveyor/blob/main/test_harness_docker.py . Upstream reported results are not a local reproduction. Its eventual-output polling is useful for integration but insufficient for this repository's exact scan boundaries.
- Beremiz documents MatIEC ST/IL-to-C compilation and native runtime: https://beremiz.readthedocs.io/en/latest/overview.html . Reuse the repository's existing matiec/GCC path rather than install another runtime.
- Open Industry Project documents tag-connected ST/LAD-driven 3D conveyors and browser/desktop modes: https://www.openindustryproject.org/ . Inspected documentation only; its language subset/physics engine are not evaluated here. Candidate for later richer scenes, not required for this small demo.
- Adopted existing repository/memory lesson: exact source and runtime evidence boundaries matter. SpecMesh continuity and CapMesh decisions/community inventory were consulted; no existing simulation adapter was found in that selected inventory. Selected Obsidian Agent topic index contains no applicable native PLC execution guidance.
- The fixed recorded agy FB_ConveyorPack is independent of canonical FB_MainSequence: Enable is startup-only in this sample. Selected prior checks do not approve the draft. Current strict mcode preflight/generation remains unchanged and is not bypassed by this historical example.
- Syntax adapter removes quoted FB name, Siemens attributes, VERSION, BEGIN, local # prefixes and // comments. No Boolean condition or transition is rewritten. Native instance per session; bounded to 16 sessions, idle eviction after 30 minutes on session creation.
- Plant is deliberately synthetic: position 0..1; each energized call advances 0.2 unless jammed. Sample pre-movement AtEnd each call. Sensor failure suppresses feedback even at position 1. Continuous playback delay 500ms is visualization pacing; timeout remains eight waiting FB calls, not elapsed wall-clock time. No inertia, mechanics or safety validation.
- Startup with AtEnd already true is not specified by frozen requirements; this initial scene is not offered. Arbitrary generated SCL cannot be uploaded into this executor.
