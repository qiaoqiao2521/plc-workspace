## 实际 Agent 操作

独立 Agent 只阅读项目入口、Skill 和协议，没有阅读实现、测试答案或已有验收文件。它通过真实 CLI 查询目录、选择模板，将新增反馈灯接到 drive.running，执行观察与正常/卡料用例；故意将电机改接 Enable，读到停止反例后仅修场景，并复验通过。

它又通过公共 CLI 查询 OIP 原子目录、真实组装项目、传入明确的当前十二次等待 program 进行物理复核，并将上游自测单独报告。把推料 profile 交给目前仅支持输送的 OIP 桥时得到明确拒绝，未回落成错误示例。交互轨迹的 not_run 与独立用例的 pass 分别保留，未靠导出成功声称程序通过。

共 40 次真实 CLI 调用，新增反馈灯的正常/卡料用例分别 64/41 项检查通过，修复接线后的停止用例 14 项通过。批次预算收尾后重启服务，分别复跑正确 normal 和错误 Stop，两份最终报告均绑定当前合同哈希。完整 185 份原始记录、命令、请求/响应保存在 [`evidence/agent-acceptance/raw-evidence.zip`](evidence/agent-acceptance/raw-evidence.zip)，可直接审阅的精选请求/报告及方法说明在 [Agent 验收目录](evidence/agent-acceptance/README.md)。旧哈希报告保留为历史，不改写成新验收。
