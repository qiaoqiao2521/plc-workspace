# PLC 可组装仿真接入

日期：2026-11-26。基线：`master@95a79cce91db70b24d4d42b7221b483ae49af7c4`。

用户先要求与 PLC 逻辑对应、AI 可调用、原子化可组装且有良好视觉的验证入口，随后明确授权“全部接入，测试一下先，你用子代理试试”。本切片扩展旧固定输送仿真；旧 Harness 计划中的完整仿真器非目标不再用于阻断本次明确范围。生成器的 S3/S4、规范 FB_MainSequence 与 Siemens 验收仍按原范围独立维护。

## 交付范围

1. 主工作台和移动端都有仿真入口，同一服务发现并提供仿真 API。
2. 当前导出工程的源文件与请求身份绑定到本次原生执行，历史验收不随导入恢复。
3. 参数化开关、灯、电机、输送段、光电、气缸和工件；类型化连接与 PLC I/O 绑定；可导入、组装与保存。
4. 单步、批跑、故障注入、独立用例、逐扫描轨迹和首个反例；同一快照驱动三维视图与诊断。
5. 现有 Agent CLI 暴露同一 API；由实际子代理从公开入口完成组装和故障试跑。
6. 固定版本接入 Open Industry Project 的源索引、安装/运行入口、项目测试和原生 PLC 到设备世界的步进桥；保留许可与实测边界。

## 运行与判断

仅云端工作，不接用户电脑或现场设备。已有规范 ST 和历史输送候选保持原样。新增推料单元为明确的合成教学合同，不替真实设备决定工艺。

原生代码在独立进程执行，编译及扫描有超时；不支持的接口、缺工具、执行崩溃不得降级为动画通过。扫描次数与物理步长分别记录。验证预期在控制代码之前定义；正常、卡料、传感器失效、气缸不到位、停止/恢复及错误变体都须有实测。

仿真通过仅表示指定源码、场景及测试范围内的结果；不授予 TIA、PLCSIM、真实机械或安全验收。OIP 原生测试与本仓库原生代码驱动 OIP 的结果分开记录。

## 分工与检查

- 核心子代理：设备合同、持久原生实例、运行记录与独立用例。
- 界面子代理：组装编辑、三维观察、当前工程交接、移动端入口。
- OIP 子代理：固定上游、真实 CLI 测试与原生闭环适配。
- 主代理：HTTP/CLI、身份校验、合流、回归、实际 Agent 操作验证与交付。

不以自动化夹具回答冒充实际 Agent 调用，不把未执行的浏览器或外部平台检查记作通过。
